## ✨ 주요 관심 영역

| 영역 | 설명 |
|---|---|
| UI/UX 디자인 | 사용자 중심의 흐름과 직관적인 인터페이스를 설계합니다. |
| 웹디자인 | 브랜드 감성과 서비스 목적에 맞는 웹 화면을 디자인합니다. |
| 인터랙션 | 자연스럽고 몰입감 있는 사용자 경험을 고민합니다. |
| 디자인 시스템 | 컬러, 타이포그래피, 컴포넌트를 일관성 있게 구성합니다. |
